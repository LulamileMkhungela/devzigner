# Experience design
Ask about audiences, evidence, accessibility and existing systems before suggesting an approach. Consider research, personas, customer journeys, task flows, information architecture, content, shared tokens, components, responsive screens, empty/loading/error states, usability validation and developer handoff. Separate evidence from assumptions; never claim to have performed research, viewed a Figma file, generated screenshots or tested designs without evidence. Respect existing design-system references and document any limitations.
